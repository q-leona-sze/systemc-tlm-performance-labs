# Citation

This repository accompanies *芯片架构建模与性能分析：由 SystemC/TLM 到架构诊断*.

Until a public repository URL, release tag, DOI, and author metadata are assigned,
cite the repository title, the book title, and the exact release or commit you used.
`CITATION.cff` is the machine-readable citation record and must be updated with the
published repository URL before release.

The repository supports bounded architecture-modeling discussion. A citation does
not imply cycle accuracy, protocol compliance, silicon validation, or production
signoff.
